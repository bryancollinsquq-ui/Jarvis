# Jarvis — Local Voice Assistant

A voice assistant that runs on your own machine, powered by the Claude API.

## Setup (do this once)

1. **Open this folder in VS Code**
   File → Open Folder → select this `jarvis-vscode` folder.

2. **Open the built-in terminal**
   Menu bar → Terminal → New Terminal (or `` Ctrl+` ``).

3. **Install dependencies**
   ```
   npm install
   ```

4. **Add your API key(s)**
   - Copy `.env.example` to a new file named `.env`
   - Open `.env` and paste your real Anthropic API key in
   - Get a key at https://console.anthropic.com if you don't have one
   - **Optional**: also add an OpenAI key from https://platform.openai.com/api-keys —
     if present, Jarvis automatically falls back to GPT-4o any time Claude fails,
     so it never just goes silent

5. **Start the server**
   ```
   npm start
   ```
   You should see: `🟢 Jarvis is running: http://localhost:3000`

6. **Open it in your browser**
   Go to `http://localhost:3000` in **Chrome or Edge** (voice recognition needs one of these).
   Allow microphone access when prompted.

## Using it

- Tap the glowing core → it listens → speak → it replies out loud.
- **Activity Log** (left panel) shows a live feed of every message, error, and
  model fallback in real time.
- **System Metrics** (right panel) shows messages today, uptime, and how many
  calls went to Claude vs. GPT. This is real data generated by your own usage —
  not mock numbers — it just resets when you restart the server, since nothing
  is saved to a database yet (that's Phase 2: long-term memory).
- "Reset memory" clears the conversation history so it forgets prior context.

## Customizing it

- **Personality**: edit `SYSTEM_PROMPT` in `server.js`.
- **Voice**: `speechSynthesis` in `public/index.html` uses your browser's built-in
  voices. You can pick a specific one — ask me and I'll show you how.
- **Give it real abilities** (checking data, running code, etc.): this is the
  next step up — called "tool use" — and it's a natural next thing to add
  once this base is solid.

## Troubleshooting

- **"Missing ANTHROPIC_API_KEY"** — you forgot to create `.env` from `.env.example`, or the key wasn't pasted in correctly.
- **Mic button does nothing** — you're not in Chrome/Edge, or you denied mic permission (check the site permissions icon in the address bar).
- **"Could not reach the local server"** — the terminal running `npm start` was closed. Restart it.
